# 阶段0：冻结范围与分析口径

> 文档日期：2026-07-28
> 基线日期：2026-07-27
> 对应工程阶段：《分阶段操作步骤》第0阶段

## 1. 阶段目标

阶段0的目标是在开始任何工程实施之前，将以下内容冻结为机器可读取、可测试、可追溯的配置和文档：

- 测试对象范围（16只A股 + ETHUSDT）
- 证券代码映射规则
- 数据时间范围
- 复权口径选择
- 所有分析指标的定义、参数和计算规则
- 命名规范（尤其是"疑似主力行为特征"）
- 数据存储和可复现要求

本阶段**不联网、不安装依赖、不调用AKShare、不抓取任何真实数据、不进入阶段1及以后**。

## 2. 冻结结果

### 2.1 测试对象

| 类别 | 数量 | 锁定内容 |
|---|---|---|
| A股 | 16 | `002067, 002600, 002230, 600763, 603259, 603799, 601012, 600438, 002361, 601500, 600231, 300274, 601636, 002129, 000100, 300433` |
| 加密货币 | 1 | `ETHUSDT`，要求精确匹配，禁止交易对替代 |

### 2.2 证券代码映射规则

- `600`/`601`/`603` 开头 → `exchange: SH`，`market_lower: sh`
- `000`/`002`/`300` 开头 → `exchange: SZ`，`market_lower: sz`
- `symbol_em = exchange + symbol`（如 `SH600763`）
- 股票代码统一为6位字符串，禁止转成整数

### 2.3 日期与时间范围

- 基线日期：`2026-07-27`
- 每次运行日期必须通过配置或CLI显式传入，禁止在业务代码中静默使用系统当天日期
- A股日线：基准日前3个自然年（验收最低1个自然年）
- 涨跌停统计：基准日前365个自然日取数，再按交易日及证券状态过滤
- 财务数据：最近5个年度报告 + 最近12个季度
- 资金流：接口实际可用的全部历史
- 实时行情和估值：保存执行时点快照

### 2.4 复权口径

| 用途 | 复权类型 | 说明 |
|---|---|---|
| 趋势、收益、均线 | `qfq`（前复权） | 用于技术指标计算 |
| 涨跌停识别 | 不复权 | 必须使用真实交易价格 |
| 长期财富曲线 | `hfq`（后复权） | 可选 |

禁止在同一个指标中混合不同复权口径。

### 2.5 均线与量价指标

- 均线窗口：`3, 5, 7, 10, 13, 20, 21`
- 成交量均线窗口：`5, 20`
- 日收益率：`close / previous_close - 1`
- 量比（20日）：`volume_share / volume_ma_20`
- 放量阈值：`volume_ratio_20 >= 2.0`
- 大涨大跌阈值：`abs(return_1d) >= 0.05`
- 波动率窗口：20个交易日，年化交易日数：252

### 2.6 活跃度评分

- 回看窗口：120个交易日
- 方法：16只测试股票之间的横截面分位数评分
- 权重：成交额分位数 0.25 + 换手率分位数 0.20 + 波动率分位数 0.20 + 放量频率分位数 0.15 + 大涨大跌频率分位数 0.10 + 涨跌停/跳空事件频率分位数 0.10
- 必须保存所有组成分数

### 2.7 涨跌停识别

- 禁止固定 ±10%，必须考虑交易所、板块、ST历史、上市状态、规则生效日期、最小报价单位
- 优先级：接口直接提供的限价 → 理论计算 → 半个最小报价单位容差匹配
- 股池仅用于校验，不能作为全年历史事件的唯一来源
- 后续收益窗口：1, 3, 5, 10个交易日

### 2.8 横盘震荡与风格

- 分析窗口：20, 40, 60个交易日，主窗口40
- 趋势斜率：对 log(close) 按交易日序号OLS回归的每日斜率
- 至少保留10个特征字段（箱体宽度、趋势斜率、R²、布林带宽度等）
- 风格标签：温和箱体型、高波动震荡型、放量冲击型、低活跃盘整型、趋势型、证据不足
- 每个结果必须输出置信度和解释

### 2.9 基本面与估值

- 12个必选基本面指标
- 必须保存报告期、公告日期、更新时间、修订版本、是否累计口径
- 累计利润表和现金流量表后续转为单季度（阶段0只定义规则）
- 估值是时点快照，禁止用当前快照回填历史
- PE为负或缺失时标记为亏损/不可用

### 2.10 盈亏比

- 收益分布盈亏比：平均正收益 / 平均负收益绝对值
- 策略盈亏比：需明确定义入场、出场、止损和持有期后才能计算

### 2.11 命名规范

- 所有与"主力行为"相关的输出统一使用"疑似主力行为特征"
- 禁止输出确定性主力行为结论
- 必须保存特征证据、置信度和解释

### 2.12 数据可复现要求

- Raw数据追加保存，不覆盖历史
- 保存接口名、参数、抓取时间、AKShare版本、Schema哈希
- 空DataFrame和调用失败分开记录
- 每次运行生成唯一 run_id
- 数据库写入幂等
- 不输出投资建议

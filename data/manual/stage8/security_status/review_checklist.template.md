# 权威证券状态历史人工审核清单

> 每条状态区间必须由两人独立复核并签字；任何一项未通过都不得发布。

## 来源核查
- [ ] 来源属于 A 级（交易所正式公告/官方检索证据或可下载正式文件）。
- [ ] 来源不是当前快照、东财风险警示板或新浪曾用名列表。
- [ ] `source_document_id`、`source_reference` 与原始文件一一对应。
- [ ] `sources/` 原始文件存在，且 `Get-FileHash` 与登记 SHA-256 一致。

## 状态内容
- [ ] 股票代码为 6 位，交易所与代码前缀一致。
- [ ] `status_type` 为 `ST` 或 `LISTING`，`status_value` 在允许集合中。
- [ ] 非 ST 区间由官方证据支持，不是“当前无 ST 名称”推断出来的。
- [ ] ST/*ST 起止日期与官方公告生效日期一致。
- [ ] `announcement_date` 不晚于使用日期 `2026-07-27`。
- [ ] 同一股票同一状态类型不存在重叠区间。

## 覆盖
- [ ] 覆盖全部 16 只样本股票在分析窗口 `2025-07-27` 至 `2026-07-27`
      每一天的 `ST` 与 `LISTING` 状态。
- [ ] 覆盖 S15-14 抽样股票及其事件日期。

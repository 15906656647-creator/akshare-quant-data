# 权威证券状态历史校验说明

`stage8-status-build`（以及组合校验命令）会对 `security_status/` 数据集按
以下阶段依次执行，任何阶段失败都返回非零并阻止发布：

1. 格式验证：`dataset.yml` 与 `security_status_history.csv` 存在且可解析；
   列名必须与 `dataset.schema.yml` 一致；不允许未知列；不允许重复
   `record_id`；记录不能为空。
2. 字段验证：股票代码、交易所、板块、状态类型/值、日期、SHA-256、审核
   状态、复核人逐一校验；`announcement_date` 不得晚于使用日期。
3. 来源验证：`raw_file` 必须在 `sources` 中登记且等级为 `A`；新浪曾用名等
   无生效日期来源令牌会被拒绝。
4. 哈希验证：原始文件存在且 SHA-256 与登记一致。
5. 区间验证：生效区间合法且覆盖分析窗口。
6. 冲突验证：同一股票同一状态类型不允许重叠；`ST` 与 `LISTING` 分属不同
   类型，允许并行存在。
7. 覆盖验证：16 只样本股票在窗口内每天恰好一条 `ST` 与一条 `LISTING`；
   组合校验还会检查 S15-14 抽样股票和事件日期。
8. 发布：全部通过后原子写入清单、配置与校验/溯源 JSON；失败不留半成品。

## 禁止事项

- 不得用当前快照、名称包含 ST 或曾用名自动生成正式状态区间。
- 不得把 B/C 级来源升级为 A 级。
- 不得生成、推测或伪造状态数据；示例文件不得进入正式构建。
